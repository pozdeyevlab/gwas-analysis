# GBMI-II Anschutz Code Base

This repository holds all code required to run major analysis conducted in the phase-II GBMI endocrine disease investiagtion completed under Dr. Nikita Pozdeyev at the CU Anschutz School of Medicine. 

To protect the data privacy of our collaborators current repos with example data, contain datasets that are either entirely randomly generated or are already publicly available.

To best replicate the methods used in [Global multi-ancestry genome-wide analyses identify genes and biological pathways associated with thyroid cancer and benign thyroid diseases](https://pubmed.ncbi.nlm.nih.gov/40463558/) follow this order:

1) [gnomad-query](https://github.com/pozdeyevlab/gwas-analysis/tree/main/gnomad-query)
2) [gwasqc](https://github.com/pozdeyevlab/gwas-analysis/tree/main/gwasqc)
3) [run-summix](https://github.com/pozdeyevlab/gwas-analysis/tree/main/run-summix)
4) [make-custom-ldref](https://github.com/pozdeyevlab/gwas-analysis/tree/main/make-custom-ldref)
5) [run-ldsc](https://github.com/pozdeyevlab/gwas-analysis/tree/main/run-ldsc)
6) [run-metal](https://github.com/pozdeyevlab/gwas-analysis/tree/main/run-metal)
7) [run-prscs](https://github.com/pozdeyevlab/gwas-analysis/tree/main/run-prscs)
8) [manual-prs](https://github.com/pozdeyevlab/gwas-analysis/tree/main/manual-prs)
9) [ld-clumping](https://github.com/pozdeyevlab/gwas-analysis/tree/main/ld-clumping)
10) [combine-leads](https://github.com/pozdeyevlab/gwas-analysis/tree/main/combine-leads)
11) [add-twas](https://github.com/pozdeyevlab/gwas-analysis/tree/main/add-twas)
